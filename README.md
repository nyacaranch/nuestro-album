# Nuestro álbum
Álbum de recuerdos con portada de libro animada y cinco capítulos que se descubren al desplazarse.

Abre index.html o sirve la carpeta con python -m http.server 3000.

## Fotografías
Los tres espacios están en blanco. Reemplaza cada div con clase photo-placeholder de index.html por una etiqueta img con la ruta de tu fotografía y un texto alt descriptivo. Puedes crear una carpeta public/fotos para tus imágenes.

## Personalización
Edita textos en index.html, colores y portada en styles.css y comportamiento en script.js.
Las notas se guardan únicamente en el navegador y dispositivo actuales.
Se incluye soporte para teclado y movimiento reducido.
No se incluyen las fotografías ni recursos visuales de la invitación original.
